# Sounds für das OBS-Overlay

Lege Sounddateien in diesem Ordner ab und pushe sie zu GitHub. Render übernimmt sie beim nächsten Deploy.

Unterstützte Formate: MP3, WAV, OGG und M4A. Verwende für den Dateinamen Buchstaben, Zahlen, `-` oder `_`, zum Beispiel `fuss-spuren.mp3`.

Öffne danach die Hub-Adminseite, wähle bei der passenden Sound-Aktion die Datei aus und speichere die Einstellungen. Ohne ausgewählte Datei spielt die Aktion den kurzen Standard-Signalton.
